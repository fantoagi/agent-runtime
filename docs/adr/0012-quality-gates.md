# ADR-0012：可靠性质量门禁与发布合同

- **状态**：Accepted
- **日期**：2026-08-15
- **决策人**：Agent Runtime Maintainers
- **关联变更**：[E2026-08-15-004](../CHANGELOG.md#e2026-08-15-004)

## 背景

现有功能缺少统一 lint、类型、覆盖率、跨平台和安装产物合同，重构容易产生静默回退。

## 决策

PR 执行 Ruff、Mypy strict、全量测试、coverage、文档、20 并发、构建和 Wheel smoke；Nightly 执行 100 并发、故障测试重复、30 分钟 soak 和性能检查。

## 影响

### 优点

既有公共行为成为可执行合同，跨平台和安装问题更早暴露。

### 代价

CI 时间和测试维护成本增加。

## 被放弃的方案

只运行 pytest，无法阻止类型、分支、安装和资源稳定性回退。

## 后续约束

降低门禁或更新性能基线必须有审查证据并同步演进文档。
