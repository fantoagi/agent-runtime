# ADR-0013：同步 Tool 隔离与 UNKNOWN Outcome

- **状态**：Accepted
- **日期**：2026-08-15
- **决策人**：Agent Runtime Maintainers
- **关联变更**：[E2026-08-15-005](../CHANGELOG.md#e2026-08-15-005)

## 背景

同步 Handler 会阻塞 Event Loop；Python 线程不能安全强杀，副作用超时不能假装取消成功。

## 决策

同步 Tool 使用 Runtime 独享有界线程池和背压；无副作用超时失败，副作用调用后超时、暂停、取消或关闭进入 `UNKNOWN`，禁止自动重试。

## 影响

### 优点

其他 Run 不被阻塞，资源数量有界，不确定副作用不会被误报。

### 代价

已启动线程可能继续运行，UNKNOWN 需要人工确认。

## 被放弃的方案

无限创建线程或超时后自动重试都会带来资源泄漏或重复副作用。

## 后续约束

未来执行器和 Sandbox 必须保留 UNKNOWN、幂等键、审批和成功持久化边界。
